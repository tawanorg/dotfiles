# Dotagent

Runtime, Mastra Studio, project memory, tests and installation now live in
[github.com/tawanorg/dotagent](https://github.com/tawanorg/dotagent).

This repository contains thin Claude Code/Codex adapters. Both load the installed
canonical playbook at ~/.local/share/dotagent/PLAYBOOK.md.

From a configured project: `dotagent start --host codex` or `dotagent start --host claude`.
From anywhere: `dotagent --project coterie start --host codex`.
